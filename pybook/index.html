معرفی و تاریخچه

تصور کنید می‌خواهیم نرم‌افزاری بسازیم که اطلاعات یک فایل Excel را بخواند، فروش ماهانه را تحلیل کند، نمودار بسازد و حتی با استفاده از هوش مصنوعی فروش آینده را پیش‌بینی کند. برای چنین کاری به یک زبان برنامه‌نویسی نیاز داریم.

پایتون (Python) یکی از زبان‌هایی است که انجام این کارها را نسبتاً ساده می‌کند؛ به دلیل سادگی یادگیری، کتابخانه‌های متنوع و جامعهٔ توسعه‌دهندگان گسترده.

پایتون چیست؟

پایتون یک زبان برنامه‌نویسی سطح بالا، عمومی (General-Purpose) و چندمنظوره است که با هدف خوانایی کد و سادگی استفاده طراحی شده است. زبان سطح بالا یعنی برنامه‌نویس به‌جای درگیر شدن با جزئیات پیچیدهٔ سخت‌افزار، بیشتر روی حل مسئله تمرکز می‌کند.

print("Hello, Python!")

  • print یک تابع آماده برای نمایش خروجی است.
  • متن داخل کوتیشن، داده‌ای است که می‌خواهیم نمایش دهیم.
  • اجرای دستور باعث نمایش متن در خروجی می‌شود.

ویژگی‌ها، مزایا و محدودیت‌ها

برای شناخت بهتر پایتون، سه موضوع را از یکدیگر جدا می‌کنیم:

  • ویژگی: پایتون چگونه طراحی شده است؟
  • مزیت: این ویژگی چه کمکی به ما می‌کند؟
  • محدودیت: در چه شرایطی ممکن است انتخاب مناسبی نباشد؟

ویژگی‌های اصلی

  1. خوانایی بالا (Readability) — ساختار دستورات پایتون به زبان طبیعی نزدیک است و کدهای آن معمولاً ساده و قابل فهم هستند.
  2. سطح بالا بودن (High-Level) — برنامه‌نویس معمولاً نیازی ندارد مدیریت مستقیم حافظه را دستی انجام دهد.
  3. مفسری بودن (Interpreted) — محیط اجرا کد را به دستورهای قابل اجرا تبدیل و اجرا می‌کند.
  4. چندسکویی بودن (Cross-Platform) — اجرا روی Windows، Linux و macOS با رعایت سازگاری و وابستگی‌ها.
  5. شیءگرا و چندسبکی بودن — پشتیبانی از برنامه‌نویسی شیءگرا، رویه‌ای و تابعی.
  6. کتابخانه‌های گسترده — کدهای آماده‌ای که قابلیت‌های مختلفی در اختیار برنامه‌نویس قرار می‌دهند.

محدودیت‌های پایتون

پایتون با وجود مزایای فراوان، برای همهٔ مسائل بهترین انتخاب نیست.

  1. سرعت اجرای کمتر در برخی سناریوها — در بسیاری از محاسبات سنگین، کد خالص پایتون از زبان‌هایی مانند C و C++ کندتر است. البته بسیاری از کتابخانه‌های علمی پایتون عملیات سنگین را با کدهای بهینه‌شدهٔ C، C++ یا Fortran انجام می‌دهند.
  2. مصرف حافظه — در بعضی کاربردها، برنامه‌های پایتون حافظهٔ بیشتری نسبت به پیاده‌سازی‌های سطح پایین‌تر مصرف می‌کنند.
  3. محدودیت در اجرای هم‌زمان Threadها در CPython — قفل GIL می‌تواند اجرای هم‌زمان Threadهای پایتونی را در محاسبات CPU-bound محدود کند. روش‌های جایگزینی مانند Multiprocessing وجود دارند.
  4. مناسب نبودن برای برخی کاربردهای خاص — توسعهٔ سیستم‌عامل، درایور سخت‌افزار و برخی سیستم‌های بلادرنگ با محدودیت زمانی بسیار سخت معمولاً با زبان‌های دیگری انجام می‌شود.

کاربردهای واقعی پایتون

یکی از مهم‌ترین دلایل محبوبیت پایتون این است که می‌توان از یک زبان واحد برای حل مسائل کاملاً متفاوت استفاده کرد. چهار حوزهٔ مهم را بررسی می‌کنیم.

کاربرد اول: هوش مصنوعی و یادگیری ماشین

هوش مصنوعی حوزه‌ای از علوم کامپیوتر است که هدف آن ساخت سیستم‌هایی است که بتوانند وظایفی مانند تشخیص تصویر، فهم زبان، پیش‌بینی و تصمیم‌گیری را انجام دهند. پایتون در این حوزه به دلیل کتابخانه‌های قدرتمند و سهولت آزمایش مدل‌ها بسیار پرکاربرد است.

  2. بررسی و آماده‌سازی داده‌ها.

  5. استفاده از نتایج برای بهبود بازاریابی.

کاربرد دوم: توسعهٔ وب

توسعهٔ وب یعنی ساخت وب‌سایت‌ها و برنامه‌های تحت وب. پایتون بیشتر در بخش Backend استفاده می‌شود — بخشی از برنامه که در سمت سرور اجرا می‌شود و مسئول پردازش درخواست‌ها، ارتباط با پایگاه داده و اجرای منطق برنامه است.

وقتی وارد یک فروشگاه اینترنتی می‌شوید:

  • Frontend: صفحه‌ای که محصولات و دکمهٔ خرید را نمایش می‌دهد.
  • Backend: بررسی اطلاعات ورود، پردازش سفارش و محاسبهٔ قیمت.
  • Database: ذخیرهٔ اطلاعات کاربران و سفارش‌ها.

کاربرد سوم: اتوماسیون

اتوماسیون یعنی خودکارسازی کارهایی که معمولاً انسان به‌صورت دستی انجام می‌دهد. پایتون برای انجام کارهای تکراری بسیار مناسب است. مثال‌ها:

  • تغییر نام تعداد زیادی فایل.
  • مرتب‌سازی فایل‌ها در پوشه‌ها.
  • استخراج اطلاعات از فایل‌های Excel.
  • ارسال خودکار گزارش‌ها.
  • پردازش فایل‌های متنی.
  • جمع‌آوری اطلاعات از وب‌سایت‌ها در چارچوب مجاز.

مثال عملی: تغییر نام خودکار فایل‌ها — فرض کنید تعداد زیادی فایل در یک پوشه داریم و می‌خواهیم نام همه را با پیشوند report_ مشخص کنیم.

rename.py
import os

folder = "reports"

for index, filename in enumerate(os.listdir(folder), start=1):
    old_path = os.path.join(folder, filename)

    if os.path.isfile(old_path):
        extension = os.path.splitext(filename)[1]
        new_name = f"report_{index}{extension}"

        new_path = os.path.join(folder, new_name)

        os.rename(old_path, new_path)

توضیح کد:

  • import os: ابزارهای کار با فایل و پوشه را وارد می‌کند.
  • os.listdir(): نام موارد موجود در پوشه را دریافت می‌کند.
  • enumerate(): شماره‌گذاری فایل‌ها را انجام می‌دهد.
  • os.path.isfile(): بررسی می‌کند مورد موردنظر فایل باشد.
  • os.rename(): نام فایل را تغییر می‌دهد.
نکتهٔ اجرایی

این کد را ابتدا روی یک پوشهٔ آزمایشی و نسخهٔ کپی فایل‌ها اجرا کنید؛ زیرا تغییر نام فایل‌ها مستقیماً روی فایل‌های موجود اثر می‌گذارد.

مفسر و نحوه اجرای کد

در جلسهٔ اول یاد گرفتیم پایتون چیست و چه کاربردهایی دارد. اما برای نوشتن و اجرای برنامه‌های پایتون، ابتدا باید سه جزء اصلی را روی سیستم آماده کنیم:

  • Python Interpreter — اجرای کدهای پایتون
  • Terminal / Command Prompt — اجرای دستورات و مدیریت برنامه
  • IDE / Code Editor — نوشتن، ویرایش و اشکال‌زدایی کد

در این جلسه یاد می‌گیریم این اجزا را نصب، تنظیم و به یکدیگر متصل کنیم تا اولین برنامهٔ پایتون خود را اجرا کنیم.

مفسر چیست؟

مفسر برنامه‌ای است که کد نوشته‌شده با یک زبان برنامه‌نویسی را پردازش می‌کند و امکان اجرای آن را فراهم می‌سازد. کامپیوتر به‌صورت مستقیم دستورات سطح بالای پایتون را اجرا نمی‌کند؛ بنابراین به محیط اجرایی پایتون نیاز داریم. یکی از پیاده‌سازی‌های اصلی پایتون، CPython است که با زبان C نوشته شده است.

فرایند اجرای کد در پایتون

وقتی یک فایل پایتون را اجرا می‌کنیم، در پیاده‌سازی رایج CPython مراحل کلی زیر اتفاق می‌افتد:

  1. کد منبع — فایلی مانند hello.py نوشته می‌شود.
  2. Bytecode Compilation — کد به بایت‌کد تبدیل می‌شود.
  3. Python Virtual Machine — ماشین مجازی پایتون بایت‌کد را اجرا می‌کند.
  4. Output — نتیجهٔ اجرای برنامه نمایش داده می‌شود.
نکته

فایل‌های Bytecode ممکن است در پوشهٔ __pycache__ ذخیره شوند. وجود این پوشه به معنی فایل اجرایی مستقل نیست.

این بخش یکی از مهم‌ترین قسمت‌های راه‌اندازی پایتون است؛ زیرا بسیاری از خطاهای اولیه هنگام اجرای پایتون به تنظیم نبودن PATH مربوط می‌شوند.

متغیر محیطی چیست؟

متغیر محیطی اطلاعاتی است که سیستم‌عامل در اختیار برنامه‌ها قرار می‌دهد؛ مانند مسیر نصب برنامه‌ها، تنظیمات سیستم، مسیر پوشه‌های کاری و اطلاعات مربوط به محیط اجرای نرم‌افزارها.

PATH چیست؟

PATH یک متغیر محیطی مهم است که فهرستی از مسیر پوشه‌های اجرایی برنامه‌ها را نگهداری می‌کند. فرض کنید پایتون در مسیر C:\Python313\ نصب شده است. اگر این مسیر در PATH ثبت شده باشد، با نوشتن python در Command Prompt، سیستم‌عامل فایل اجرایی پایتون را پیدا می‌کند.

اما اگر مسیر پایتون در PATH نباشد، ممکن است با خطای زیر مواجه شویم:

terminal
'python' is not recognized as an internal or external command
مدل ذهنی PATH
  1. دستور واردشده در ترمینال — مانند python hello.py
  2. بررسی مسیرهای PATH — جست‌وجوی فایل اجرایی در پوشه‌های ثبت‌شده
  3. مسیر پیدا شد → اجرای برنامه
  4. مسیر پیدا نشد → خطای شناسایی دستور

تنظیم PATH در ویندوز

اگر هنگام نصب گزینهٔ Add Python to PATH را فعال نکرده‌اید، می‌توانید دستی تنظیم کنید:

  1. در منوی Start عبارت Environment Variables را جست‌وجو کنید.
  2. گزینهٔ Edit the system environment variables را باز کنید.
  3. روی Environment Variables کلیک کنید.
  4. در قسمت User variables، متغیر Path را انتخاب کنید.
  5. روی Edit و سپس New کلیک کنید.
  6. مسیر پوشهٔ نصب پایتون را اضافه کنید، مثلاً C:\Python313\ و همچنین C:\Python313\Scripts\
  7. پنجره‌ها را تأیید و ترمینال را ببندید و دوباره باز کنید.
  8. دستور python --version را اجرا کنید.
نکته

مسیرهای بالا صرفاً مثال هستند. باید مسیر واقعی نصب پایتون روی سیستم خودتان را وارد کنید.

محیط‌های توسعه (VS Code و PyCharm)

تا اینجا یاد گرفتیم پایتون را نصب کنیم و از طریق ترمینال کد اجرا کنیم. اما نوشتن برنامه‌های بزرگ فقط با ترمینال دشوار است. به همین دلیل از محیط‌های توسعه استفاده می‌کنیم.

IDE و Code Editor چیست؟

Code Editor نرم‌افزاری برای نوشتن و ویرایش کد است. IDE (محیط توسعهٔ یکپارچه) محیطی است که امکانات مختلف برنامه‌نویسی را در یک محیط جمع می‌کند. امکانات معمول:

  • نوشتن و ویرایش کد
  • تشخیص خطاهای احتمالی
  • تکمیل خودکار دستورات
  • اجرای برنامه
  • اشکال‌زدایی (Debugging)
  • مدیریت پروژه و فایل‌ها

ابزار اول: Visual Studio Code (VS Code)

VS Code یک ویرایشگر کد است که با نصب افزونه‌ها می‌توان آن را به محیطی قدرتمند برای برنامه‌نویسی پایتون تبدیل کرد. از سایت رسمی دانلود کنید.

ویژگی‌های مهم:

  • سبک و نسبتاً کم‌حجم
  • افزونه‌های متنوع
  • پشتیبانی از زبان‌های برنامه‌نویسی مختلف
  • ترمینال داخلی
  • قابلیت Debug
  • قابلیت اتصال به Git

برای برنامه‌نویسی پایتون در VS Code معمولاً به دو افزونهٔ مهم نیاز داریم:

  • Python — افزونهٔ پشتیبانی از اجرای برنامه‌های پایتون و ابزارهای مرتبط.
  • Pylance — تکمیل خودکار، تحلیل کد و قابلیت‌های هوشمند ویرایشگر.
توجه

افزونهٔ Python و Pylance جایگزین نصب خود مفسر پایتون نیستند.

مراحل راه‌اندازی VS Code

  1. VS Code را از وب‌سایت رسمی دانلود، نصب و اجرا کنید.
  2. وارد بخش Extensions شوید.
  3. عبارت Python را جست‌وجو و افزونهٔ رسمی Microsoft را نصب کنید.
  4. در صورت نیاز Pylance را نیز نصب کنید.
  5. از منوی File گزینهٔ Open Folder را انتخاب کنید.
  6. یک پوشه برای پروژهٔ خود بسازید و باز کنید.
  7. با Ctrl+Shift+P در ویندوز/لینوکس یا Cmd+Shift+P در macOS، دستور Python: Select Interpreter را جست‌وجو کنید.
  8. نسخهٔ پایتون نصب‌شده را انتخاب کنید.
  9. یک فایل با نام main.py بسازید و کد زیر را در آن قرار دهید:
main.py
print("Hello from VS Code!")

از دکمهٔ Run Python File یا ترمینال داخلی برای اجرای برنامه استفاده کنید.

ابزار دوم: PyCharm

PyCharm یک IDE تخصصی برای توسعهٔ برنامه‌های پایتون است. برخلاف VS Code که یک ویرایشگر چندمنظوره است، PyCharm امکانات تخصصی پایتون را یکپارچه ارائه می‌دهد. از سایت رسمی JetBrains دانلود کنید.

ویژگی‌های مهم:

  • مدیریت پروژه‌های پایتون
  • تکمیل هوشمند کد
  • Debugger قدرتمند
  • مدیریت محیط‌های مجازی
  • ابزارهای تست نرم‌افزار
  • امکانات تحلیل و بازآرایی کد (Refactoring)

مراحل راه‌اندازی PyCharm

  1. از سایت رسمی JetBrains برنامه را دانلود و نصب کنید.
  2. گزینهٔ New Project را انتخاب کنید.
  3. محل ذخیرهٔ پروژه را مشخص کنید.
  4. در بخش Python Interpreter، مفسر نصب‌شده یا یک محیط مجازی جدید را انتخاب کنید.
  5. پروژه را ایجاد کنید.
  6. یک فایل پایتون با نام main.py بسازید و کد زیر را وارد کنید:
main.py
print("Hello from PyCharm!")

روی فایل کلیک راست کرده و Run را انتخاب کنید.

جمع‌بندی مفهومی

چهار مفهوم اصلی این جلسه مکمل یکدیگرند:

  • Code Editor / IDE — محل نوشتن، ویرایش و مدیریت کد
  • Interpreter — مسئول اجرای کد پایتون
  • Terminal — محل وارد کردن دستورات و اجرای برنامه
  • PATH — کمک به سیستم‌عامل برای یافتن فایل اجرایی

بنابراین اگر برنامه در ویرایشگر نوشته شده اما اجرا نمی‌شود، لزوماً مشکل از کد نیست؛ ممکن است مفسر انتخاب نشده باشد یا مسیر اجرایی درست تنظیم نشده باشد.

سناریوی ترکیبی: نصب و اجرای اولین پروژه در VS Code

فرض کنید یک برنامه‌نویس تازه‌کار می‌خواهد روی ویندوز پروژه‌ای به نام first_project ایجاد کند.

  1. نصب Python — از سایت رسمی نسخهٔ پایدار Python 3 را نصب و در زمان نصب گزینهٔ Add python.exe to PATH را فعال کنید.
  2. بررسی نصب — Command Prompt را باز و اجرا کنید: python --version و where python
  3. ایجاد پروژه — پوشهٔ first_project با فایل main.py بسازید.
  4. تنظیم VS Code — پوشه را باز و افزونهٔ Python را نصب کنید؛ سپس با Python: Select Interpreter مفسر را انتخاب کنید.
  5. نوشتن برنامه — در main.py بنویسید:
main.py
name = "Ali"

print("Welcome to Python")
print("Hello", name)

سپس در ترمینال داخلی VS Code اجرا کنید:

terminal
python main.py
Welcome to Python Hello Ali
بررسی یک خطای احتمالی

اگر هنگام اجرا خطای python is not recognized گرفتید:

  1. بررسی کنید Python نصب شده باشد.
  2. دستور where python را امتحان کنید.
  3. اگر مسیر پیدا نشد، PATH را بررسی و اصلاح کنید.
  4. ترمینال را ببندید و دوباره باز کنید.
  5. مجدداً نسخه و اجرای فایل را بررسی کنید.

اگر دستور python کار نمی‌کند، ممکن است دستور py در ویندوز همچنان قابل استفاده باشد. همچنین اگر برنامه در VS Code اجرا نمی‌شود، انتخاب Interpreter را بررسی کنید؛ این مشکل لزوماً با اصلاح PATH حل نمی‌شود.

روش‌های اجرای کد

پایتون زبانی است که کدهای آن معمولاً به‌صورت دستورهای متنی نوشته می‌شوند. برای اجرای این دستورها به مفسر پایتون نیاز داریم. سه روش رایج کار با پایتون:

  • REPL — اجرای فوری دستورها به‌صورت تعاملی.
  • Terminal — اجرای دستورها و فایل‌های پایتون از طریق خط فرمان.
  • فایل .py — ذخیرهٔ برنامه در یک فایل و اجرای آن در صورت نیاز.

انتخاب روش مناسب به نوع کاری که انجام می‌دهی بستگی دارد؛ برای آزمایش سریع REPL مناسب است، اما برای ساخت برنامه‌های واقعی معمولاً از فایل‌های .py استفاده می‌کنیم.

الف) محیط تعاملی (REPL)

REPL مخفف عبارت‌های زیر است:

  • Read: خواندن دستور
  • Evaluate: ارزیابی و اجرا
  • Print: نمایش نتیجه
  • Loop: تکرار این فرایند

برای ورود به REPL در ترمینال بنویس:

terminal
python

در بعضی سیستم‌ها:

terminal
python3

حالا می‌توانی دستورها را مستقیماً وارد کنی:

REPL
>>> 2 + 3
5

>>> print("Hello Python")
Hello Python

>>> name = "Sara"
>>> name
'Sara'

برای خروج:

REPL
exit()

یا در محیط‌های معمول:

  • Windows: Ctrl+Z و سپس Enter
  • macOS / Linux: Ctrl+D

الف) کامنت (Comment) چیست؟

کامنت متنی توضیحی در کد است که مفسر پایتون آن را به‌عنوان دستور اجرایی در نظر نمی‌گیرد. کامنت با علامت # شروع می‌شود.

price = 100
tax = 10

کاربردهای کامنت:

  • توضیح هدف یک بخش از برنامه
  • مشخص کردن منطق پیچیده
  • یادآوری نکات مهم
  • کمک به برنامه‌نویسان دیگر برای فهم کد

ب) انواع کامنت

۱. کامنت تک‌خطی — برای توضیح کوتاه:

single_line.py
# User information

age = 22

۲. کامنت انتهای خط (Inline Comment) — در ادامهٔ یک دستور:

نکته

کامنت انتهای خط را فقط زمانی استفاده کن که واقعاً به توضیح نیاز باشد. استفادهٔ زیاد از آن کد را شلوغ می‌کند.

۳. کامنت چندخطی — پایتون علامت اختصاصی کامنت چندخطی ندارد؛ می‌توان چند خط کامنت را با # نوشت:

multi_line.py
# This program calculates
# the total price of products
# and displays the result

price = 100
quantity = 3

print(price * quantity)
نکته

گاهی از سه علامت نقل‌قول (''' یا """) برای متن چندخطی استفاده می‌شود، اما این‌ها به‌خودی‌خود کامنت نیستند؛ بلکه رشته‌های متنی هستند.

ج) Docstring چیست؟

Docstring مخفف Documentation String است؛ یعنی رشته‌ای برای مستندسازی یک ماژول، کلاس یا تابع. معمولاً در اولین خط داخل آن بخش نوشته می‌شود و از سه علامت نقل‌قول استفاده می‌کند.

docstring.py
def calculate_sum(a, b):
    """Return the sum of two numbers."""
    return a + b

در اینجا:

  • def تابع را تعریف می‌کند.
  • calculate_sum نام تابع است.
  • a و b ورودی‌های تابع هستند.
  • متن داخل سه علامت نقل‌قول، Docstring است.
  • return نتیجه را برمی‌گرداند.

برای مشاهدهٔ مستندات تابع می‌توان از help() استفاده کرد:

REPL
help(calculate_sum)

جمع‌بندی مفهومی و سناریو

نکات مهم و کلیدی

  1. int برای اعداد صحیح، float برای اعداد اعشاری و complex برای اعداد مختلط استفاده می‌شود.
  2. در پایتون برای بخش موهومی عدد مختلط از j استفاده می‌کنیم.
  3. نوع bool فقط دو مقدار True و False دارد.
  4. خروجی عملگرهای مقایسه‌ای معمولاً یک مقدار بولی است.
  5. مقادیر 0، False، None و رشتهٔ خالی از مقادیر Falsy هستند؛ اما نوع و مفهوم یکسانی ندارند.
  6. رشته‌ها با کوتیشن تکی، دوتایی یا سه‌تایی تعریف می‌شوند.
  7. اندیس رشته از صفر شروع می‌شود و اندیس منفی از انتهای رشته حرکت می‌کند.
  8. رشته‌ها Immutable هستند؛ یعنی محتوای آن‌ها مستقیماً قابل تغییر نیست.
  9. None برای نمایش نبود مقدار مشخص استفاده می‌شود و نوع آن NoneType است.
  10. برای بررسی مقدار تهی از is None استفاده کن.
  11. تابع type() نوع دقیق شیء و isinstance() تعلق شیء به یک نوع یا خانوادهٔ نوع‌ها را بررسی می‌کند.
  12. تابع input() همیشه ورودی را به شکل str برمی‌گرداند؛ در صورت نیاز باید آن را تبدیل کنی.

انتخاب نوع دادهٔ مناسب

برای انتخاب نوع دادهٔ مناسب، این سؤال‌ها را از خودت بپرس:

  • آیا داده عدد صحیح است؟ از int استفاده کن.
  • آیا عدد اعشاری است؟ از float استفاده کن.
  • آیا محاسبهٔ مختلط داری؟ از complex استفاده کن.
  • آیا فقط درست یا نادرست بودن مهم است؟ از bool استفاده کن.
  • آیا داده متنی است؟ از str استفاده کن.
  • آیا فعلاً مقداری وجود ندارد؟ از None استفاده کن.

تبدیل ضمنی و صریح

در پایتون تبدیل نوع داده به دو روش اصلی انجام می‌شود:

  • تبدیل ضمنی (Implicit Type Conversion) — پایتون خودش نوع داده را در شرایط مناسب تبدیل می‌کند.
  • تبدیل صریح (Explicit Type Conversion) — برنامه‌نویس با استفاده از توابع تبدیل، نوع داده را مشخصاً تغییر می‌دهد.

تبدیل ضمنی (Implicit)

در تبدیل ضمنی، پایتون بدون اینکه ما تابعی مثل int() یا float() را صدا بزنیم، نوع داده را تغییر می‌دهد.

implicit.py
a = 10       # int
b = 2.5      # float

result = a + b

print(result)
print(type(result))
12.5 <class 'float'>

چرا نتیجه float است؟ چون پایتون هنگام جمع یک عدد صحیح با یک عدد اعشاری، عدد صحیح را به نوع اعشاری ارتقا می‌دهد تا محاسبه به‌درستی انجام شود.

division.py
x = 5
y = 2

result = x / y

print(result)
print(type(result))
2.5 <class 'float'>

عملگر / در پایتون نتیجهٔ تقسیم را به شکل float برمی‌گرداند؛ حتی اگر حاصل تقسیم دقیقاً یک عدد صحیح باشد:

div_float.py
print(10 / 2)
print(type(10 / 2))
5.0 <class 'float'>

نکات مهم و کلیدی

  • input() همیشه مقدار را به شکل str برمی‌گرداند.
  • برای محاسبات عددی روی ورودی کاربر، معمولاً باید از int() یا float() استفاده کنیم.
  • int(7.9) برابر 7 است، نه 8.
  • int("7.9") خطا می‌دهد؛ اما int(float("7.9")) برابر 7 است.
  • تبدیل int به float معمولاً بدون از دست رفتن مقدار عددی انجام می‌شود؛ اما تبدیل float به int بخش اعشاری را حذف می‌کند.

  • پایتون در محاسبات عددی می‌تواند تبدیل ضمنی انجام دهد؛ اما رشته و عدد را خودکار برای جمع با هم سازگار نمی‌کند.
  • تبدیل صریح باید با توجه به محتوای واقعی داده انجام شود؛ هر رشته‌ای الزاماً قابل تبدیل به عدد نیست.
  • برای جلوگیری از توقف برنامه هنگام تبدیل ورودی نامعتبر، از try/except استفاده می‌کنیم.

عملگرهای مقایسه‌ای برای بررسی رابطهٔ بین دو مقدار استفاده می‌شوند. نتیجهٔ آن‌ها همیشه یک مقدار منطقی از نوع bool است؛ یعنی True یا False. فرض کنیم:

تقدم و ترتیب اجرای عملگرها

وقتی چند عملگر در یک عبارت وجود داشته باشند، پایتون باید مشخص کند کدام عملیات را زودتر اجرا کند. به این اولویت‌ها، تقدم عملگرها می‌گوییم.

  2. سپس 2 + 12 محاسبه می‌شود.

ترکیب مقایسه با and و or

عملگرهای منطقی را در جلسات مربوط به منطق و شرط‌ها کامل‌تر بررسی می‌کنیم؛ اما اینجا یک نمونه از تقدم آن‌ها می‌بینیم:

logic_mix.py
age = 25
has_ticket = True

result = age >= 18 and has_ticket == True

print(result)
True

مقایسه‌ها ابتدا محاسبه می‌شوند و سپس and نتیجهٔ آن‌ها را ترکیب می‌کند. در عمل معمولاً نیازی نیست بنویسیم has_ticket == True؛ شکل ساده‌تر این است:

simpler.py
result = age >= 18 and has_ticket
پرانتز؛ راهکار خوانایی کد

حتی اگر تقدم عملگرها را بدانیم، استفاده از پرانتز می‌تواند خوانایی برنامه را بهتر کند:

clear.py
total = 100 + (20 * 3) - 10

پیشنهاد حرفه‌ای: وقتی عبارت پیچیده است یا ممکن است خواننده ترتیب اجرا را اشتباه برداشت کند، از پرانتز استفاده کن.

سناریوی ترکیبی: محاسبهٔ مبلغ خرید و بررسی تخفیف

فرض کن فروشگاهی برای خریدهای بالاتر از ۵۰۰ هزار تومان، ۱۰ درصد تخفیف در نظر گرفته است.

discount.py
price = 150000
quantity = 4

total = price * quantity

discount = total * 0.10

if total >= 500000:
    final_price = total - discount
else:
    final_price = total

print(f"Total: {total}")
print(f"Discount: {discount}")
print(f"Final price: {final_price}")
Total: 600000 Discount: 60000.0 Final price: 540000.0

تحلیل مرحله‌ای:

  1. price * quantity مبلغ اولیهٔ خرید را محاسبه می‌کند.
  2. total * 0.10 مقدار تخفیف را محاسبه می‌کند.
  3. total >= 500000 بررسی می‌کند آیا خرید مشمول تخفیف است.
  4. اگر شرط درست باشد، تخفیف از مبلغ کل کم می‌شود.
  5. در پایان، مبلغ نهایی نمایش داده می‌شود.

نسخهٔ تکمیلی: بررسی شرایط سفارش

order.py
price = 150000
quantity = 4

total = price * quantity

is_valid_quantity = quantity > 0
is_eligible = total >= 500000

if is_valid_quantity and is_eligible:
    final_price = total * 0.90
    print("Discount applied!")
elif is_valid_quantity:
    final_price = total
    print("No discount.")
else:
    final_price = 0
    print("Invalid quantity.")

print(f"Final price: {final_price}")

این نسخه علاوه بر محاسبات، از مقایسه و ترکیب شرط‌ها نیز استفاده می‌کند.

نکات مهم و کلیدی جلسه

  1. / همیشه نتیجه‌ای از نوع float می‌دهد.
  2. // تقسیم را به سمت منفی بی‌نهایت گرد می‌کند؛ فقط حذف اعشار نیست.
  3. % باقیماندهٔ تقسیم را محاسبه می‌کند و برای تشخیص زوج یا فرد بودن کاربرد دارد.
  4. ** برای محاسبهٔ توان استفاده می‌شود.
  5. == برای مقایسهٔ برابری است؛ = برای انتساب.
  6. خروجی عملگرهای مقایسه‌ای همیشه bool است.
  7. مقایسهٔ رشته‌ها به بزرگی و کوچکی حروف حساس است.
  8. پرانتزها ترتیب اجرای عملیات را مشخص می‌کنند.
  9. توان ** از راست به چپ گروه‌بندی می‌شود.
  10. تقسیم بر صفر با ZeroDivisionError مواجه می‌شود.

  • تفاوت is و == را تشخیص بدهی.
  • از این عملگرها در سناریوهای واقعی برنامه‌نویسی استفاده کنی.

عملگرهای منطقی

عملگرهای منطقی برای ترکیب یا تغییر نتیجهٔ شرط‌ها استفاده می‌شوند. نتیجهٔ آن‌ها در ساده‌ترین حالت True یا False است؛ البته در پایتون and و or می‌توانند خودِ یکی از عملوندها را نیز برگردانند که کمی جلوتر توضیح می‌دهیم.

  • or
  • not

نکتهٔ حرفه‌ای: Short-Circuit Evaluation

پایتون در عملگرهای and و or از ارزیابی کوتاه‌شونده استفاده می‌کند. یعنی اگر نتیجهٔ عبارت از همان بخش اول مشخص باشد، بخش بعدی را اجرا نمی‌کند.

short_circuit.py
x = 0
result = x != 0 and 10 / x > 2

print(result)
False

چرا خطای تقسیم بر صفر رخ نداد؟ چون شرط اول False است؛ بنابراین پایتون نیازی ندارد شرط دوم را بررسی کند. در or نیز اگر بخش اول True باشد، بخش دوم ارزیابی نمی‌شود:

short_circuit_or.py
result = True or (10 / 0 > 1)

print(result)
True

این رفتار در جلوگیری از برخی خطاها و بهینه‌سازی ارزیابی شرط‌ها بسیار مفید است.

نکتهٔ تکمیلی: and و or همیشه Boolean برنمی‌گردانند

در پایتون، and و or الزاماً True یا False برنمی‌گردانند؛ ممکن است یکی از خود مقادیر را برگردانند.

return_value.py
print("Python" and 10)
print("" or "Default")
10 Default
  • and اگر مقدار اول Truthy باشد، مقدار دوم را برمی‌گرداند؛ در غیر این صورت مقدار اول را.
  • or اگر مقدار اول Truthy باشد، همان مقدار اول را برمی‌گرداند؛ در غیر این صورت مقدار دوم را.
نکته

این ویژگی در تعیین مقدار پیش‌فرض کاربرد دارد، ولی برای مبتدیان بهتر است ابتدا منطق True و False را کاملاً یاد بگیرند.

عملگرهای عضویت

عملگرهای عضویت برای بررسی وجود یا عدم وجود یک مقدار در یک مجموعه یا ساختار داده استفاده می‌شوند. دو عملگر اصلی: in و not in.

عملگر in

بررسی می‌کند آیا یک مقدار در یک مجموعه وجود دارد یا خیر.

languages = ["Python", "Java", "C++"]

print("PHP" in languages)
True False

چون Python در لیست وجود دارد، نتیجه True است؛ اما PHP وجود ندارد. مثال با رشته:

عملگرهای هویتی

عملگرهای هویتی بررسی می‌کنند آیا دو متغیر به یک شیء واحد در حافظه اشاره می‌کنند یا خیر. دو عملگر: is و is not. برای درک این موضوع باید تفاوت «برابری مقدار» و «یکسان بودن هویت شیء» را بدانیم.

تفاوت == و is

  • == بررسی می‌کند آیا مقدار دو شیء برابر است.
  • is بررسی می‌کند آیا دو متغیر دقیقاً به یک شیء واحد اشاره می‌کنند.
compare.py
list_a = [1, 2, 3]
list_b = [1, 2, 3]

print(list_a == list_b)
print(list_a is list_b)
True False

چرا؟ چون محتوای دو لیست برابر است، اما دو لیست مستقل ساخته شده‌اند. در این مثال، برابری مقدار درست است، اما یکسان بودن هویت شیء نادرست است.

چه زمانی is برابر True می‌شود؟

اگر دو متغیر به یک شیء واحد اشاره کنند، is مقدار True برمی‌گرداند.

same_object.py
list_a = [1, 2, 3]
list_b = list_a

print(list_a == list_b)
print(list_a is list_b)
True True

چون list_b = list_a یک لیست جدید نمی‌سازد؛ بلکه نام دیگری برای دسترسی به همان شیء ایجاد می‌کند. حالا اگر یکی از لیست‌ها را تغییر دهیم:

mutate.py
list_b.append(4)

print(list_a)
print(list_b)
[1, 2, 3, 4] [1, 2, 3, 4]

چون هر دو متغیر به یک لیست اشاره می‌کنند.

عملگر is not

این عملگر بررسی می‌کند آیا دو متغیر به دو شیء متفاوت اشاره می‌کنند یا خیر.

is_not.py
a = [10, 20]
b = [10, 20]

print(a is not b)
True

چون دو لیست مستقل هستند.

کاربرد مهم is برای بررسی None

یکی از مهم‌ترین کاربردهای is بررسی مقدار None است.

is_none.py
result = None

if result is None:
    print("No result available")
No result available

برای بررسی نبودن مقدار نیز می‌توانیم بنویسیم:

not_none.py
if result is not None:
    print("Result is available")
else:
    print("Result is missing")
چرا از is None استفاده می‌کنیم؟

چون None یک مقدار یکتاست و بررسی هویت آن روش استاندارد و مطمئنی برای تشخیص نبودن مقدار است.

آیا باید برای مقایسهٔ اعداد از is استفاده کنیم؟

خیر! این کار اشتباه است:

wrong_is.py
a = 1000
b = 1000

print(a is b)

ممکن است بسته به جزئیات پیاده‌سازی و شرایط اجرا، نتیجه‌ای متفاوت از انتظار داشته باشد. برای مقایسهٔ مقدار عددی باید از == استفاده کنیم:

right_compare.py
print(a == b)
True
قاعدهٔ مهم
  • برای مقایسهٔ مقدارها: == و !=
  • برای بررسی هویت اشیا: is و is not
  • برای بررسی نبودن مقدار: is None و is not None

سناریوی ترکیبی: بررسی دسترسی کاربر به یک سامانه

فرض کن یک سامانه داریم که باید چند شرط را بررسی کند: کاربر فعال باشد، سن کاربر حداقل ۱۸ سال باشد، نقش کاربر مدیر یا کارمند باشد، نام کاربر در فهرست کاربران مجاز وجود داشته باشد و اطلاعات کاربر مقدار None نباشد.

access.py
user = {
    "name": "Sara",
    "age": 25,
    "role": "manager",
    "active": True
}

allowed_users = ["Sara", "Ali", "Reza"]
allowed_roles = ["admin", "manager"]

if (
    user is not None
    and user["active"]
    and user["age"] >= 18
    and user["role"] in allowed_roles
    and user["name"] in allowed_users
):
    print("Access granted")
else:
    print("Access denied")
Access granted

تحلیل مرحله‌ای:

  1. user is not None بررسی می‌کند اطلاعات کاربر وجود داشته باشد.
  2. user["active"] فعال بودن حساب را بررسی می‌کند.
  3. user["age"] >= 18 شرط سنی را کنترل می‌کند.
  4. user["role"] in allowed_roles نقش مجاز را بررسی می‌کند.
  5. user["name"] in allowed_users حضور نام در فهرست مجاز را بررسی می‌کند.
  6. and تضمین می‌کند همهٔ شرط‌ها باید درست باشند.
نکتهٔ ایمنی

در این مثال فرض کرده‌ایم ساختار دیکشنری کامل است و کلیدهای موردنیاز وجود دارند. در برنامهٔ واقعی باید ورودی‌ها را اعتبارسنجی کنیم تا در صورت نبودن کلید، خطای KeyError رخ ندهد.
